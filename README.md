# UTS Pengkodean dan Pemrograman

Repository ini berisi dokumentasi dan hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pengkodean dan Pemrograman. Repository disusun untuk mengumpulkan hasil perancangan database, implementasi SQL, pengembangan web, pengujian, serta dokumentasi pengerjaan tugas.

## 📁 Struktur Repository

```text
UTS-Pengkodean-Pemrograman/
├── 01-ERD/
│   ├── ERD_General_Ledger.dot
│   ├── ERD_General_Ledger.drawio
│   ├── ERD_General_Ledger.mmd
│   ├── ERD_General_Ledger.png
│   └── ERD_General_Ledger.svg
├── 02-SQL/
│   ├── soal1_integrity.sql
│   ├── soal1_schema.sql
│   ├── soal2_inventory.sql
│   ├── soal3_audit_immutability.sql
│   ├── soal3_schema.sql
│   └── soal3_voucher_rpc.sql
├── 03-WEB/
│   └── index.html
├── 04-LOG-AI/
├── 05-BUKTI/
│   └── Dokumentasi hasil pengujian
├── 06-LAPORAN/
└── README.md
```

## 🗂️ Deskripsi Folder

- **01-ERD** — Berisi diagram Entity Relationship Diagram (ERD) beserta file sumber dan hasil visualisasi rancangan database General Ledger.
- **02-SQL** — Berisi kumpulan script SQL untuk perancangan skema database, integritas data, inventaris, audit immutability, dan voucher RPC.
- **03-WEB** — Berisi file web berbasis HTML.
- **04-LOG-AI** — Disediakan untuk dokumentasi atau log penggunaan AI selama pengerjaan, jika diperlukan.
- **05-BUKTI** — Berisi screenshot dan bukti hasil pengujian.
- **06-LAPORAN** — Disediakan untuk laporan akhir pengerjaan UTS.

## 🛠️ Teknologi dan Tools

- SQL untuk pengelolaan dan pengujian database.
- HTML untuk pengembangan halaman web.
- Draw.io dan Mermaid untuk visualisasi diagram ERD.
- Visual Studio Code sebagai editor kode.
- Git dan GitHub untuk version control dan penyimpanan repository.

## 🚀 Cara Mengakses

1. Buka folder atau file yang ingin diperiksa melalui repository ini.
2. Buka file diagram ERD dengan aplikasi yang mendukung formatnya.
3. Jalankan script SQL menggunakan DBMS yang sesuai dengan sintaks dan kebutuhan script.
4. Buka file `03-WEB/index.html` melalui browser untuk melihat halaman web.

## 📝 Catatan

Repository ini digunakan untuk dokumentasi dan pengumpulan hasil pengerjaan UTS Pengkodean dan Pemrograman.
